# 引き継ぎ: ikesu（Go 版 herdr）の次の段階（2026-10-07）

## 店長の方針（2026-10-07 決定）

- **MoonBit 版（moonterrace）はやめて、Go 版（このリポジトリ、コマンド `ikesu`）で進める。**
  理由: ビルドの待ち時間が圧倒的に短い（下の計測）。
- **最重要は性能。** まず今のシンプルな状態のまま、大量出力の処理がどこまで速くなるかを詰める。
- そのあとで、できる限り店長のフォーク版 herdr（`~/src/github.com/kazuph/herdr`、読むだけ）の
  `SPEC.md`（1,882 行）に沿って機能を足し、herdr に近づける。
- **ビルド・計測・重いテストは Mac mini（`ssh mini`）で行う。** このメインの Mac は店長が作業中で、
  計測で重くなったと指摘があった。メインの Mac で重い処理（大きなビルド、計測、ヘッドレス Chrome など）を回さない。

## ここまでの結果（Mac mini・Apple M2・8コアで計測）

ビルド（秒）:

| 作業 | herdr（Rust） | MoonBit 版 | Go 版 |
|---|---|---|---|
| 開発用・最初から | 63.2 | 4.3 | 3.4 |
| 開発用・1ファイル変更後 | 4.4〜5.0 | 2.9 | 0.1 |
| 配布用・最初から | 103.1 | 24.6 | 3.5 |
| 配布用・1ファイル変更後 | 50.3〜50.8 | 13.3〜18.5 | 0.1 |

200万行の出力（160×45 の同じ端末、3回の中央値）:

| | 時間 | CPU 時間 | メモリ | 端末へ送ったデータ量 |
|---|---|---|---|---|
| 素の zsh | 1.8秒 | ― | ― | 65MB |
| herdr（Rust・配布用） | **1.6秒** | 1.9秒 | 28MB | 0.06MB |
| Go 版（配布用、`go build -trimpath -ldflags=-s -w`） | **46.8秒（herdr の約29倍）** | 49.4秒 | 34MB | 1.5MB |

- Go 版は端末へ送る量は少ない（描画の差分送信は効いている）のに、CPU を出力時間と同じだけ使っている。
  **ペインの出力を読んで処理する側のどこかが重い。原因はまだ測っていない**（候補: 端末エンジン
  `charmbracelet/x/vt`、出力のたびの画面全体の読み直し、エージェント検出の呼び出し頻度。どれも未検証）。
- まず Go の pprof で、200万行を流している最中の CPU プロファイルを mini で取り、原因を特定してから直すこと。
  推測で直さない。直したら同じ計測で前後を比べる。
- 端末エンジンを Ghostty（herdr と同じ libghostty-vt）に替える案は、cgo と zig が必要になりビルドの手軽さ
  （上の 0.1秒）を損なう可能性がある。替える場合は店長に判断材料を出して確認する。

## Mac mini の計測環境（そのまま使える）

- 置き場所: mini の `~/bench-terrace.noindex/`（名前の `.noindex` は Spotlight の索引対象から外すため）
  - `tools/go`（Go 1.27.0）、`tools/moon`（不要になった MoonBit）
  - `src/ikesu`（2026-10-07 時点のコピー。**最新はメインの Mac から rsync し直す**）、`src/herdr`（ccb002ce の複製）
  - `work/herdr-target/release/herdr`（比較用の herdr 配布用ビルド）、`work/ptyrun`（計測用の道具）
  - `env.sh`（PATH などの設定）、`bench_build.sh`、`bench_rt.sh`
- 同じスクリプトと計測用の道具のソースを、このリポジトリの `tools/bench/` に置いた（未コミット）。
  - `tools/bench/ptyrun/`: 固定サイズの PTY でアプリを動かし、手順書どおりにキー・クリックを送って画面を読む道具。
    PTY は即時に読み出し、画面の再現は別に追いかける（道具が遅くて測りたいアプリを待たせないため）。
  - `bench_rt.sh`: 素の zsh・herdr・MoonBit 版・Go 版の中で `python3 tp.py`（200万行を出力）を走らせ、
    かかった時間・CPU・メモリ・送ったデータ量を記録する。Go 版だけ測るなら run の行を絞る。
  - herdr はまっさらな設定だと最初に「ワークスペースが無い」画面が出て計測コマンドが実行されない。
    `work/hx/` に設定が残っているので、それを使い回す。
- mini には写真の解析（mediaanalysisd）などがもともと動いていて、負荷が 5〜12 ほどある。計測結果には開始時の負荷も書く。
