# 画面の選択と再接続

`ikesu agent start` の既定は画面を移さない動作です。herdr の既定とは異なります。新しいエージェントへ移る場合は `--focus`、従来の明示指定には `--no-focus` を使えます。API の `agent.start` は従来どおり `focus` を参照します。

明示的な workspace/tab/pane focus は接続中の全画面へ配送します。画面内のクリック・キー選択、通知クリックによる移動も維持します。終了・削除・並べ替えだけでは、他の画面が見ているスペースとタブの ID を変えません。表示対象が消えた画面だけ、先頭の存続スペース／タブへ補正します。同一タブのペイン選択は従来どおり画面間で共有します。

端末クライアントは接続が切れる直前に受信していた画面のスペース ID・各スペースのタブ ID・表示中タブのペイン ID を再接続の `hello.selection` に含めます。サーバー引き継ぎでも同じ経路を使います。サーバーは存続する ID のみ復元します。スペースが消えていたら先頭スペース、タブが消えていたらそのスペースの先頭タブ、ペインが消えていたら選択タブのレイアウトの先頭ペインへ移ります。すべてなくなったときのホーム画面への復帰は変更しません。`selection` を送らない旧クライアントは従来のセッション選択から始まります。

プラグインの `placement=zoomed, focus=false` は拡大状態と対象タブ内のペイン選択を保ちつつ、別スペース・別タブへの移動と全画面追従を止めます。同じタブを表示中の画面には拡大が見えます。同一タブの選択共有は変更しません。明示的な `pane.zoom` API の動作も変更しません。
