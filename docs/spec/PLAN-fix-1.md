## 直し方

### 3番（最優先。4番と1番もこれで直る可能性が高い）

- `Unknown` の入力を **ペインへ送らない**。捨てる。
- 切れ端の扱い。`moonbit-community/tty` は変更しないこと（依存の変更は禁止）。mt 側で、tty の decoder が返したイベント列を見て、
  herdr と同じ考え方で次の2つを捨てる:
  - (a) `ESC [ <` で始まり、数字と `;` だけが続く `Unknown`（途中で切れたマウスの信号）。その直後に続く `数字;` の文字キーと、
    終わりの `M` / `m` も一緒に捨てる
  - (b) Escape キーの直後に `[<` から始まって `数字;…` と `M` / `m` で終わる文字キーが続いた場合（ESC だけが先に届いた場合）。
    Escape キーも含めて全部捨てる
  - 捨てる処理には上限を設ける（herdr と同じく、マウスの信号1つ分を超える長さになったら、捨てるのをやめて普通の入力として扱う）
- 可能なら、切れた残りを捨てる代わりに、つなぎ直して正しいマウスイベントとして処理する（クリックを失わないため）。
  無理なら捨てるだけでよい。どちらにしたかを RESULT.md に書く。
- `esc_timeout_ms` を 50 から伸ばすかどうかは、伸ばすと Esc キー単独の反応が遅れるので、herdr の扱いを読んで決め、理由を書く。
- テスト: decoder の出力を模したイベント列（切れたマウスの信号、ESC だけ先に届いた信号、普通の Esc キー、普通の `[` 入力、
  `Alt+[`）で、ペインへ送られるバイトが正しいこと（ゴミが出ず、普通の入力は消えない）を単体テストにする。
  e2e テストに「マウスの信号を2回に分けて送ってもシェルに文字が出ない」ケースを足す（親が再現した手順と同じ）。

### 2番

- herdr と同じにする。フォーカス中のペインのカーソルが非表示でも、**そのカーソル位置**へ外側の端末のカーソルを置いてから、
  非表示のままにする。位置が取れないときは、最後に表示されていたカーソル位置、それも無ければペインの左上。
- 描画の最後のカーソル指定は、同期出力ブロックの外でもう一度出す（herdr の `repeat_ime_anchor_after_sync`。macOS の IME 向け）。

### 1番

- 描画を herdr の `render_ansi.rs` の1〜5と同じ順番にする:
  1. フレームの最初に `ESC [ ? 2026 h`（同期出力の開始）、最後に `ESC [ ? 2026 l`
  2. セルを書く前にカーソルを隠す（`ESC [ ? 25 l`）
  3. 前のフレームとの差分だけを書く（初回とサイズ変更時だけ全画面）
  4. 書き終えたら、2番のカーソル位置へ移動してから表示/非表示を設定
- 3番を直したあと、実物（mt の中で claude を動かして回転記号が出ている状態で、マウスを動かす）で「ゴミ」が出なくなったか確かめる。
  まだ出るなら `herdr pane read --format ansi` で何が出ているかを記録し、原因を RESULT.md に書いて親へ報告する（推測で直さない）。

### 4番

- 3番を直したあと、実物で確かめる: 左に claude、右に codex を開き、マウスを動かしながら左右のペインを交互にクリックし、
  そのつど短い文字（例: `aaa`、`bbb`）を打って、クリックしたペインに入ることを `herdr pane read` で確認する（Enter は押さない。
  打った文字は確認後に消す）。これを10回以上繰り返す。
- それでも直らなければ、どの入力がどこへ行ったかを記録して親へ報告する。

### 5番

- 最後の1枚のペインで `Close pane`（右クリックメニュー、ステータス行の `[close]`、`Ctrl-b x`）を選んだら、
  そのワークスペースを閉じる確認ダイアログ（PLAN-mouse 3.2 の `Close workspace?`）を出す。

## 追加 6番（店長の指摘 2026-10-06 10:36）: 起動してすぐ閉じると `69;12m` のようなゴミがシェルに出る

- 店長の指摘（原文）: 起動してすぐ閉じると、こうやって69;12mみたいなゴミがでる。なんで？
- 親の見立て（**推測。実物で確かめること**）: `69;12m` はマウスの信号（`ESC [ < 35 ; 69 ; 12 m`）の後ろ半分。mt が終了してマウスの受け取りを
  止める前後に、外側の端末がすでに送っていたマウス移動の信号が入力に残り、mt の終了後にシェルが読んで、zsh が先頭の `ESC [ <35;` だけを
  解釈して残りを文字として表示している。
- 直し方: 終了時に (1) マウスの受け取りを止める命令を出して書き出しきる → (2) 入力に残っているバイトを短い時間（例: 100ms）読み捨てる、
  または `tcflush(TCIFLUSH)` 相当で捨てる → (3) raw mode と代替画面を戻す、の順にする。C スタブが必要なら `src/platform/` に置く。
- 確認: herdr の検証用ペインで mt を起動し、マウスの信号を連続で送りながら `Ctrl-b q` → Enter で終了し、終了後のシェルの行に
  ゴミが出ないことを `herdr pane read` で確かめる（直す前に、同じ手順でゴミが出ることを先に確かめて記録する）。
